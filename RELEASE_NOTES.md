# GestureBind v0.7.0

GestureBind is now prepared as a cleaner release snapshot: the repository keeps the project source, current documentation, active CI/CD workflows and production model artifacts needed to run and evaluate the system.

## Highlights

- Production dynamic model line: `dynamic_landmark_lstm_backbone`.
- Cleaner repository layout for GitHub release presentation.
- Release bundle workflow publishes a GitHub Release from version tags.
- CI, ML smoke checks and Docker runtime checks are aligned with the current repository structure.
- Recurrent backbone training/CI path is stabilized.
- Application launch bindings are easier to configure in the desktop UI.

## Included In The Release

- Desktop application source code.
- Static gesture model artifacts and intent gate metadata.
- Dynamic landmark LSTM backbone artifacts.
- Current setup, training, command binding and CI/CD documentation.
- Source bundle generated by GitHub Actions.
