# Чеклист beta-тестирования

Цель: перед раздачей beta-версии проверить основной пользовательский путь
GestureBind и зафиксировать проблемы, которые мешают первому запуску.

## 1. Твое smoke-тестирование

- [ ] Приложение запускается без терминальных ошибок.
- [ ] База и seed-данные доступны после старта.
- [ ] Главный экран открывает камеру и показывает live preview.
- [ ] Распознавание включается и выключается без зависаний.
- [ ] Минимум один статический жест распознается стабильно.
- [ ] Минимум один динамический жест распознается стабильно.
- [ ] Экран «Жесты» показывает словарь и статус привязки.
- [ ] Экран «Обучение» может записать новый жест.
- [ ] Экран «Привязки» создает связку жест -> команда.
- [ ] Кнопка «Проверить запуск» выполняет сохраненную команду.
- [ ] Предупреждение R6 появляется для опасного действия на одноручном жесте.
- [ ] Повторное сохранение привязки заменяет старую команду по правилу R1.
- [ ] Настройки политики сохраняются и применяются после перезапуска.

## 2. Тестирование на пользователях

Попросить 3-5 человек пройти один и тот же сценарий:

1. Запустить приложение.
2. Включить камеру.
3. Выбрать или записать жест.
4. Привязать жест к простой команде.
5. Проверить команду кнопкой на экране привязок.
6. Выполнить жест 10 раз подряд.
7. Попробовать 10 секунд обычных движений без жеста.

## 3. Что записывать

- Имя тестера или номер сессии.
- Устройство и ОС.
- Сработало ли приложение с первого запуска.
- Сколько из 10 попыток жеста были успешными.
- Были ли ложные срабатывания без жеста.
- Что было непонятно в интерфейсе.
- Какая команда/жест вызвали ошибку.

## 4. Минимальный критерий beta

- У 3 пользователей из 5 приложение запускается без помощи разработчика.
- Основной жест срабатывает минимум 8 раз из 10.
- Нет опасных ложных срабатываний в idle-сценарии.
- Привязка жеста к команде понятна без объяснения кода или терминала.
