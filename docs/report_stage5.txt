GestureBind: Gesture Assistant — Отчёт по проекту
Этап 5 — GUI (PySide6): превью камеры, базовые кнопки

Цели этапа:
- Создать каркас десктоп‑приложения на PySide6 (Qt for Python).
- Отобразить превью камеры в окне (OpenCV → QImage → QLabel/QPixmap).
- Добавить базовые элементы управления: запуск инференса, запись жестов (заглушки).
- Подготовить структуру для дальнейшей интеграции функционала (TTS, CRUD словаря).

Архитектура GUI:
- app/gui_main.py — точка входа, MainWindow и виджет превью.
- Поток/таймер для опроса камеры: QTimer на UI‑потоке (30 FPS), без блокировок.
- В дальнейшем: выделить сервисы (видеопоток/ML) в отдельные классы и связывать сигналами.

Команда запуска:
- python -m app.gui_main

Критерии готовности:
- Открывается окно, отображается видеопоток с камеры.
- Кнопки «Старт инференса», «Запись жеста» пока выводят уведомления (заглушки).

Дальнейшие шаги:
- Связать кнопки с фактическими сценариями (реальный запуск record_gestures.py / realtime_infer.py).
- Добавить панель словаря жестов (CRUD), настройки аудио/камеры.
