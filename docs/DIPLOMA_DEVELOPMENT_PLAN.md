# План по разработке дипломного проекта

**Тема:** Система с функцией обучения для распознавания жестов на основе собственного словаря

## 1. Цель и задачи проекта

### 1.1. Цель
Разработать интеллектуальную систему управления компьютером с помощью жестов, позволяющую пользователю создавать собственный словарь жестов, обучать систему распознаванию и привязывать жесты к произвольным командам.

### 1.2. Задачи
1. Исследовать методы детекции и классификации жестов в реальном времени.
2. Реализовать модуль извлечения признаков на базе MediaPipe Hands.
3. Разработать механизм обучения на пользовательских данных (KNN/SVM).
4. Применить алгоритмы оптимизации гиперпараметров (байесовская оптимизация).
5. Создать графический интерфейс для обучения, управления словарём и выполнения команд.
6. Интегрировать систему с базой данных и механизмом выполнения команд.
7. Провести тестирование и оценить точность распознавания.

## 6. Риски и меры по их снижению

| Риск | Вероятность | Мера |
|------|-------------|------|
| Проблемы с камерой на macOS | Средняя | Использование AVFoundation, fallback на индексы |
| Низкая точность KNN | Низкая | Оптимизация гиперпараметров, переход на SVM |
| Сложность интеграции QML | Средняя | Сохранение gui_main.py (Qt Widgets) как fallback |
