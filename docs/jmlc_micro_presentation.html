Data Science

Исследование должно отвечать на один ясный вопрос

Достаточно ли static_mean для пользовательских жестов, или динамические признаки снижают ложные срабатывания без роста задержки?

A
KNN static_mean. Базовая дипломная версия и контрольная точка.
B
KNN / SVM / RF dynamic_stats. Быстрый инженерный апгрейд признаков.
C
DTW-KNN Полная последовательность. Проверка динамики жеста.
D
TCN / 1D CNN Нейросетевой вариант при большем датасете.
M
Метрики Macro F1, confusion matrix, threshold, latency, live false triggers.

Что показать комиссии

Паспорт датасета, EDA, предобработку, протокол валидации, таблицу A/B/C, матрицу ошибок и анализ порогов. Главный риск: без фактических результатов Data Science будет выглядеть как план, а не как исследование.

Текущий визуальный артефакт из `docs/plots/`: его стоит дополнить confusion matrix и threshold report.

Почему не сразу нейросеть?

Для малого персонального датасета KNN/SVM быстрее, проще и интерпретируемее. Нейросеть имеет смысл после накопления данных.

В чем исследовательская часть?

В проверке гипотезы о динамике жестов, сравнении признаков и моделей, подборе порогов и live-валидации ошибок.

Как снижаете ложные срабатывания?

Threshold, cooldown, per-class metrics, confusion matrix, live false trigger rate и recognition_logs.

Почему это продукт?

Есть пользовательский сценарий, MVP, локальные данные, журнал ошибок, настройка безопасности и метрики импакта.
