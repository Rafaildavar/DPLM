## 🎯 Что работает прямо сейчас

### ✅ Полностью функциональные компоненты:

1. **Запись жестов:**
   ```bash
   python cv/record_gestures.py --label my_gesture --num-samples 20
   ```

2. **Обучение модели:**
   ```bash
   python cv/train_classifier.py --data-root data/gestures --expect-dim 42
   ```

3. **Распознавание в реальном времени:**
   ```bash
   python cv/realtime_infer.py --model models/knn.pkl --tts
   ```

   ```bash
   python app/gui_main.py
   ```
