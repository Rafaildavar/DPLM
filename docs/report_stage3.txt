Этап 3 — Базовая классификация жестов (KNN)

Цели этапа:
- Построить базовую модель классификации жестов на записанных семплах.
- Реализовать загрузчик данных из data/gestures/<label>/sample_*.npy.
- Сформировать простые фичи (усреднение по времени) и обучить KNN.
- Сохранить модель и метаданные в models/ (для последующей онлайн‑инференции).

Детали реализации:
- Формат семпла: массив numpy формы (T, D), где D = 42×2 (две руки) или 21×2 (одна).
- Экстракция признаков: усреднение по времени (получаем вектор размера D).
- Алгоритм: KNeighborsClassifier (n_neighbors=5, metric=euclidean).
- Сохранение: models/knn.pkl (+ classes.json, feature_dim.txt).

Команда запуска:
- python cv/train_classifier.py --data-root data/gestures --out models/knn.pkl --neighbors 5

Критерии готовности:
- Успешная загрузка семплов, отчёт о количестве классов/семплов.
- Модель сохранена, доступен список классов.

Проблемы и обходные пути:
- Разная длина T: используем усреднение; позже можно добавить динамические фичи.
- Пустые папки классов: пропускать, выводить предупреждение.
