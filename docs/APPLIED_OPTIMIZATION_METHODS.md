## Вариант 1: Оптимизация гиперпараметров классификатора KNN
## Option 1: KNN Classifier Hyperparameter Optimization

### Постановка задачи / Problem Statement

**Цель**: Найти оптимальные значения гиперпараметров KNN (`k`, метрика расстояния, веса соседей), максимизирующие точность классификации жестов.

**Текущее состояние**: Используются фиксированные значения (`k=5`, `metric='euclidean'`, равномерные веса).

### Математическая формализация / Mathematical Formulation

**Целевая функция**:
```
maximize: f(k, metric, weights) = Accuracy(k, metric, weights)
```

**Ограничения**:
- `k ∈ {1, 3, 5, 7, 9, 11, 15, 21}` (дискретные значения)
- `metric ∈ {'euclidean', 'manhattan', 'chebyshev', 'minkowski'}`
- `weights ∈ {'uniform', 'distance'}`

**Метрика качества**: 
- Accuracy (точность классификации)
- F1-score (среднее по классам)
- Cross-validation score (k-fold, k=5)

### Методы оптимизации / Optimization Methods

#### 1.1 Grid Search (Полный перебор)
**Описание**: Систематический перебор всех комбинаций гиперпараметров.

**Алгоритм**:
1. Определить сетку значений для каждого параметра
2. Для каждой комбинации:
   - Обучить модель на train set
   - Оценить на validation set (cross-validation)
   - Сохранить метрику
3. Выбрать комбинацию с максимальной метрикой

**Сложность**: O(n_k × n_metric × n_weights × n_folds × n_samples)
- Где n_k = 8, n_metric = 4, n_weights = 2
- Всего комбинаций: 8 × 4 × 2 = 64

**Преимущества**:
- Простота реализации
- Гарантирует нахождение глобального оптимума в сетке
- Легко распараллелить

**Недостатки**:
- Вычислительно затратно при большом пространстве параметров
- Не учитывает зависимости между параметрами

**Библиотеки**: `sklearn.model_selection.GridSearchCV`

---

#### 1.2 Random Search (Случайный поиск)
**Описание**: Случайный выбор комбинаций гиперпараметров из заданного распределения.

**Алгоритм**:
1. Определить распределения для каждого параметра
2. Выполнить N итераций:
   - Случайно выбрать комбинацию параметров
   - Оценить метрику через cross-validation
3. Выбрать лучшую комбинацию

**Сложность**: O(N × n_folds × n_samples), где N - количество итераций (обычно 20-50)

**Преимущества**:
- Быстрее Grid Search при большом пространстве параметров
- Может найти хорошие решения быстрее

**Недостатки**:
- Не гарантирует оптимальность
- Может пропустить хорошие области пространства

**Библиотеки**: `sklearn.model_selection.RandomizedSearchCV`

---

#### 1.3 Bayesian Optimization (Байесовская оптимизация)
**Описание**: Использование вероятностной модели целевой функции для интеллектуального выбора следующих точек для оценки.

**Математическая модель**:
- **Prior**: Гауссовский процесс (Gaussian Process) для моделирования f(k, metric, weights)
- **Acquisition Function**: Expected Improvement (EI) или Upper Confidence Bound (UCB)
- **Обновление**: После каждой оценки обновляется posterior распределение

**Алгоритм**:
1. Инициализировать GP с несколькими случайными точками
2. Для каждой итерации:
   - Найти точку максимума acquisition function
   - Оценить целевую функцию в этой точке
   - Обновить GP
3. Вернуть точку с максимальным значением

**Преимущества**:
- Эффективно использует информацию о предыдущих оценках
- Требует меньше итераций, чем Random Search
- Учитывает неопределенность

**Недостатки**:
- Сложнее в реализации
- Требует настройки параметров GP

**Библиотеки**: `optuna`, `scikit-optimize`, `hyperopt`

**Пример кода (Optuna)**:
```python
import optuna
from sklearn.model_selection import cross_val_score
from sklearn.neighbors import KNeighborsClassifier

def objective(trial):
    k = trial.suggest_int('k', 1, 21, step=2)
    metric = trial.suggest_categorical('metric', ['euclidean', 'manhattan', 'chebyshev'])
    weights = trial.suggest_categorical('weights', ['uniform', 'distance'])
    
    clf = KNeighborsClassifier(n_neighbors=k, metric=metric, weights=weights)
    scores = cross_val_score(clf, X, y, cv=5, scoring='f1_macro')
    return scores.mean()

study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=100)
```

#### 1.4 Genetic Algorithm (Генетический алгоритм)
**Описание**: Эволюционный алгоритм, имитирующий естественный отбор.

**Представление решения**:
- **Хромосома**: [k, metric_index, weights_index]
- **Ген**: k (целое), metric_index (0-3), weights_index (0-1)

**Операторы**:
- **Селекция**: Tournament selection или Roulette wheel
- **Кроссовер**: Одноточечный или равномерный
- **Мутация**: Случайное изменение одного гена

**Алгоритм**:
1. Инициализировать популяцию (N решений)
2. Для каждого поколения:
   - Оценить fitness (accuracy) для каждого решения
   - Отобрать лучшие решения
   - Применить кроссовер и мутацию
   - Сформировать новое поколение
3. Вернуть лучшее решение

**Преимущества**:
- Хорошо работает с дискретными параметрами
- Может найти глобальный оптимум
- Легко распараллелить

**Недостатки**:
- Требует много итераций
- Параметры алгоритма (размер популяции, вероятность мутации) нужно настраивать

**Библиотеки**: `DEAP`, `pymoo`, `genetic_algorithm` (самостоятельная реализация)

---

### Рекомендация / Recommendation

**Для диплома рекомендуется**: **Bayesian Optimization (Optuna)**

**Обоснование**:
1. Современный и эффективный метод
2. Хорошо документирован и имеет готовые библиотеки
3. Позволяет визуализировать процесс оптимизации
4. Можно сравнить с Grid Search для демонстрации эффективности

**Метрики для оценки**:
- Количество итераций до достижения оптимального решения
- Финальная точность классификации
- Время выполнения оптимизации
- Сравнение с baseline (k=5, euclidean, uniform)

## Вариант 2: Оптимизация весов признаков (Feature Weighting)
## Option 2: Feature Weighting Optimization

### Постановка задачи / Problem Statement

**Цель**: Найти оптимальные веса для каждого признака (координат ландмарков), чтобы улучшить точность классификации. Некоторые ландмарки могут быть более информативными для определенных жестов.

**Текущее состояние**: Все признаки имеют равный вес (1.0).

### Математическая формализация / Mathematical Formulation

**Целевая функция**:
```
maximize: f(w) = Accuracy(KNN(X ⊙ w, y))
```

Где:
- `w ∈ ℝ^D` - вектор весов признаков (D = 42 или 84)
- `X ⊙ w` - поэлементное умножение (взвешивание признаков)
- Ограничения: `w_i ≥ 0` (неотрицательные веса), `Σw_i = D` (нормализация)

**Альтернативная постановка** (с регуляризацией):
```
maximize: f(w) = Accuracy(KNN(X ⊙ w, y)) - λ·||w||₁
subject to: w_i ≥ 0, i = 1, ..., D
```

Где `λ` - коэффициент регуляризации (L1 для разреженности).

### Методы оптимизации / Optimization Methods

#### 2.1 Градиентный спуск (Gradient Descent)
**Описание**: Итеративное обновление весов в направлении градиента целевой функции.

**Проблема**: Целевая функция (accuracy) не дифференцируема напрямую.

**Решение**: 
- Использовать дифференцируемый суррогат (например, softmax вероятности)
- Или использовать метод конечных разностей для аппроксимации градиента

**Алгоритм**:
1. Инициализировать `w = [1, 1, ..., 1]`
2. Для каждой итерации:
   - Вычислить градиент (аппроксимированный): `∇f(w) ≈ [f(w + ε·e_i) - f(w)] / ε`
   - Обновить веса: `w ← w + α·∇f(w)` (α - learning rate)
   - Применить проекцию на ограничения: `w ← max(0, w)`, нормализация
3. Вернуть оптимальные веса

**Сложность**: O(N_iter × D × n_samples × k)

**Библиотеки**: `scipy.optimize.minimize` (метод L-BFGS-B), самостоятельная реализация

---

#### 2.2 Particle Swarm Optimization (PSO - Роевой интеллект)
**Описание**: Алгоритм оптимизации, вдохновленный поведением стаи птиц.

**Математическая модель**:
Для каждой частицы `i`:
- **Позиция**: `x_i(t) ∈ ℝ^D` (текущие веса)
- **Скорость**: `v_i(t) ∈ ℝ^D`
- **Лучшая позиция частицы**: `p_i` (personal best)
- **Лучшая позиция роя**: `g` (global best)

**Обновление**:
```
v_i(t+1) = w·v_i(t) + c₁·r₁·(p_i - x_i(t)) + c₂·r₂·(g - x_i(t))
x_i(t+1) = x_i(t) + v_i(t+1)
```

Где:
- `w` - инерция (0.5-0.9)
- `c₁, c₂` - коэффициенты ускорения (обычно 2.0)
- `r₁, r₂` - случайные числа [0, 1]

**Алгоритм**:
1. Инициализировать рой из N частиц (случайные позиции и скорости)
2. Для каждой итерации:
   - Оценить fitness (accuracy) для каждой частицы
   - Обновить personal best и global best
   - Обновить скорости и позиции
   - Применить ограничения (проекция на w ≥ 0)
3. Вернуть global best

**Преимущества**:
- Хорошо работает с недифференцируемыми функциями
- Может найти глобальный оптимум
- Легко распараллелить

**Недостатки**:
- Требует настройки параметров (w, c₁, c₂)
- Может сходиться медленно

**Библиотеки**: `pyswarm`, `pyswarms`, самостоятельная реализация

---

#### 2.3 Simulated Annealing (Симуляция отжига)
**Описание**: Вероятностный алгоритм, имитирующий процесс отжига металла.

**Алгоритм**:
1. Инициализировать `w = [1, 1, ..., 1]`, `T = T₀` (начальная температура)
2. Для каждой итерации:
   - Сгенерировать соседа `w'` (небольшое случайное изменение)
   - Вычислить Δ = f(w') - f(w)
   - Если Δ > 0: принять `w'`
   - Иначе: принять с вероятностью `exp(Δ/T)`
   - Охладить: `T ← α·T` (α < 1, например 0.95)
3. Вернуть лучшее найденное решение

**Преимущества**:
- Простота реализации
- Может избежать локальных оптимумов
- Хорошо работает с дискретными пространствами

**Недостатки**:
- Требует настройки schedule охлаждения
- Может быть медленным

**Библиотеки**: `scipy.optimize.basinhopping`, самостоятельная реализация

---

#### 2.4 Метод множителей Лагранжа (Lagrange Multipliers)
**Описание**: Аналитический метод для оптимизации с ограничениями.

**Постановка**:
```
maximize: f(w) = Accuracy(KNN(X ⊙ w, y))
subject to: g(w) = Σw_i - D = 0, w_i ≥ 0
```

**Лагранжиан**:
```
L(w, λ) = f(w) - λ·(Σw_i - D)
```

**Условия оптимальности (KKT)**:
- `∇_w L = 0` → `∂f/∂w_i = λ` для всех i
- `g(w) = 0` (ограничение равенства)
- `w_i ≥ 0` (ограничение неравенства)

**Проблема**: Требует аналитического выражения градиента, что сложно для accuracy.

**Применение**: Можно использовать для упрощенной задачи (например, максимизация разделимости классов).

---

### Рекомендация / Recommendation

**Для диплома рекомендуется**: **Particle Swarm Optimization (PSO)**

**Обоснование**:
1. Интересный биологически вдохновленный алгоритм
2. Хорошо работает с недифференцируемыми функциями
3. Можно визуализировать движение частиц
4. Позволяет сравнить с равномерными весами

**Метрики для оценки**:
- Улучшение accuracy по сравнению с равномерными весами
- Какие признаки получили наибольшие веса (интерпретируемость)
- Время сходимости алгоритма
- Визуализация распределения весов

## Вариант 3: Оптимизация параметров нормализации
## Option 3: Normalization Parameters Optimization

### Постановка задачи / Problem Statement

**Цель**: Найти оптимальный метод нормализации и его параметры для улучшения качества признаков.

**Текущее состояние**: Используется метод `wrist_scale` с фиксированными параметрами.

### Математическая формализация / Mathematical Formulation

**Варианты нормализации**:

1. **Wrist Scale** (текущий):
   ```
   x' = (x - x_wrist) / max(||x_i - x_wrist||)
   ```

2. **Bounding Box**:
   ```
   x' = (x - center) / diagonal
   ```

3. **PCA-based** (новый):
   ```
   x' = PCA(x, n_components)
   ```

4. **Min-Max Scaling**:
   ```
   x' = (x - min) / (max - min)
   ```

**Целевая функция**:
```
maximize: f(method, params) = Accuracy(KNN(normalize(X, method, params), y))
```

**Параметры для оптимизации**:
- Метод нормализации: дискретный выбор
- Параметры метода (например, n_components для PCA)

### Методы оптимизации / Optimization Methods

#### 3.1 Комбинация Grid Search + Cross-Validation
**Описание**: Перебор методов нормализации и их параметров.

**Алгоритм**:
1. Для каждого метода нормализации:
   - Определить сетку параметров
   - Для каждой комбинации:
     - Применить нормализацию к данным
     - Обучить KNN
     - Оценить через cross-validation
2. Выбрать лучший метод и параметры

**Библиотеки**: `sklearn.model_selection.GridSearchCV` с кастомным pipeline

---

#### 3.2 Bayesian Optimization для непрерывных параметров
**Описание**: Если параметры непрерывные (например, n_components для PCA), использовать Bayesian Optimization.

**Библиотеки**: `optuna`

---

### Рекомендация / Recommendation

**Для диплома рекомендуется**: **Grid Search по методам нормализации**

**Обоснование**:
1. Простота реализации
2. Позволяет сравнить разные методы
3. Хорошая демонстрация влияния предобработки данных

## Вариант 4: Оптимизация размера окна сглаживания и весов
## Option 4: Smoothing Window Size and Weights Optimization

### Постановка задачи / Problem Statement

**Цель**: Найти оптимальный размер окна сглаживания и веса для усреднения признаков во времени, чтобы улучшить стабильность распознавания.

**Текущее состояние**: Используется равномерное усреднение по окну размера 30 кадров.

### Математическая формализация / Mathematical Formulation

**Текущий метод**:
```
x_avg = (1/N) · Σ_{i=1}^N x_i
```

**Взвешенное усреднение**:
```
x_avg = Σ_{i=1}^N w_i · x_i
subject to: Σw_i = 1, w_i ≥ 0
```

**Целевая функция**:
```
maximize: f(N, w) = Stability_Score(N, w)
```

Где Stability_Score может быть:
- Количество переключений между классами (минимизировать)
- Консистентность предсказаний (максимизировать)
- Accuracy на тестовом наборе

**Параметры**:
- `N ∈ {5, 10, 15, 20, 25, 30, 35, 40, 50}` (размер окна)
- `w ∈ ℝ^N` (веса, обычно экспоненциальные или линейные)

### Методы оптимизации / Optimization Methods

#### 4.1 Grid Search для размера окна + аналитическая оптимизация весов
**Описание**: 
- Перебор размеров окна
- Для каждого размера: аналитически найти оптимальные веса (например, экспоненциальные с параметром α)

**Экспоненциальные веса**:
```
w_i = exp(-α·(N-i)) / Σexp(-α·(N-j))
```

Где `α` - параметр затухания (оптимизируется).

**Алгоритм**:
1. Для каждого N:
   - Для каждого α:
     - Вычислить веса w(α)
     - Оценить Stability_Score
   - Выбрать оптимальный α
2. Выбрать оптимальный N и соответствующий α

---

#### 4.2 Joint Optimization через Bayesian Optimization
**Описание**: Одновременная оптимизация N и параметров весов.

**Библиотеки**: `optuna`

---

### Рекомендация / Recommendation

**Для диплома рекомендуется**: **Grid Search + экспоненциальные веса**

**Обоснование**:
1. Простота реализации
2. Хорошая интерпретируемость (больший вес последним кадрам)
3. Можно сравнить с равномерным усреднением

## Вариант 5: Многокритериальная оптимизация пороговых значений
## Option 5: Multi-Objective Optimization of Threshold Values

### Постановка задачи / Problem Statement

**Цель**: Найти оптимальные пороговые значения для confidence scores, минимизируя ложные срабатывания и максимизируя правильные распознавания.

**Параметры**:
- `confidence_threshold`: минимальный confidence для принятия предсказания
- `min_say_interval`: минимальный интервал между озвучиваниями
- `stability_threshold`: минимальное количество последовательных одинаковых предсказаний

### Математическая формализация / Mathematical Formulation

**Многокритериальная задача**:
```
maximize: [TPR(θ), -FPR(θ), -Latency(θ)]
subject to: θ ∈ Θ
```

Где:
- `TPR` - True Positive Rate (чувствительность)
- `FPR` - False Positive Rate (ложные срабатывания)
- `Latency` - задержка реакции
- `θ = [confidence_threshold, min_say_interval, stability_threshold]`

**Метод решения**: Парето-оптимизация (нахождение множества Парето-оптимальных решений)

### Методы оптимизации / Optimization Methods

#### 5.1 NSGA-II (Non-dominated Sorting Genetic Algorithm)
**Описание**: Эволюционный алгоритм для многокритериальной оптимизации.

**Алгоритм**:
1. Инициализировать популяцию
2. Для каждого поколения:
   - Вычислить fitness по всем критериям
   - Сортировка по доминированию (Pareto front)
   - Селекция, кроссовер, мутация
3. Вернуть множество Парето-оптимальных решений

**Библиотеки**: `pymoo`, `DEAP`

---

#### 5.2 Weighted Sum Method
**Описание**: Преобразование многокритериальной задачи в однокритериальную через взвешенную сумму.

```
maximize: w₁·TPR(θ) - w₂·FPR(θ) - w₃·Latency(θ)
```

Где `w₁ + w₂ + w₃ = 1`.

**Проблема**: Требует выбора весов, которые могут быть субъективными.

---

### Рекомендация / Recommendation

**Для диплома рекомендуется**: **NSGA-II для нахождения Парето-фронта**

**Обоснование**:
1. Современный метод многокритериальной оптимизации
2. Позволяет визуализировать компромиссы между критериями
3. Не требует субъективного выбора весов

## Вариант 6: Оптимизация выбора признаков (Feature Selection)
## Option 6: Feature Selection Optimization

### Постановка задачи / Problem Statement

**Цель**: Найти оптимальное подмножество признаков (координат ландмарков), которое максимизирует accuracy при минимальном количестве признаков.

**Математическая формализация**:
```
maximize: f(S) = Accuracy(KNN(X[:, S], y))
minimize: |S|
subject to: S ⊆ {1, 2, ..., D}
```

Где `S` - подмножество индексов признаков.

### Методы оптимизации / Optimization Methods

#### 6.1 Wrapper Methods (обёрточные методы)
- **Forward Selection**: Последовательно добавлять признаки
- **Backward Elimination**: Последовательно удалять признаки
- **Genetic Algorithm**: Эволюционный поиск подмножества

#### 6.2 Filter Methods (фильтрующие методы)
- **Mutual Information**: Выбор признаков с максимальной взаимной информацией
- **Chi-square**: Статистический тест
- **Variance Threshold**: Удаление низковариационных признаков

#### 6.3 Embedded Methods (встроенные методы)
- **L1 Regularization**: Использование L1-регуляризации для разреженности
- **Tree-based**: Использование важности признаков из Random Forest

### Рекомендация / Recommendation

**Для диплома рекомендуется**: **Genetic Algorithm для выбора подмножества признаков**

**Обоснование**:
1. Комбинаторная задача оптимизации
2. Можно сравнить с полным набором признаков
3. Позволяет найти компромисс между accuracy и размерностью

## Вариант 7: Оптимизация ансамбля моделей
## Option 7: Ensemble Model Optimization

### Постановка задачи / Problem Statement

**Цель**: Найти оптимальные веса для ансамбля нескольких моделей (KNN, SVM, Random Forest), максимизируя accuracy.

**Математическая формализация**:
```
maximize: f(w) = Accuracy(Σw_i · M_i(x))
subject to: Σw_i = 1, w_i ≥ 0
```

Где `M_i` - i-я модель, `w_i` - её вес.

### Методы оптимизации / Optimization Methods

#### 7.1 Linear Programming (Линейное программирование)
**Описание**: Если использовать линейную комбинацию предсказаний.

**Библиотеки**: `scipy.optimize.linprog`, `cvxpy`

#### 7.2 Quadratic Programming (Квадратичное программирование)
**Описание**: Если использовать квадратичную функцию потерь.

**Библиотеки**: `cvxpy`, `scipy.optimize.minimize`

#### 7.3 Gradient Descent
**Описание**: Если использовать softmax для комбинирования предсказаний.
