# ОТЧЕТ ПО ПРИКЛАДНЫМ МЕТОДАМ ОПТИМИЗАЦИИ
**Тема:** Сравнительный анализ прикладных методов оптимизации гиперпараметров классификатора в интеллектуальной системе распознавания жестов

---

## 1. Введение
### 1.1. Постановка проблемы
В интеллектуальных системах, основанных на машинном обучении, качество работы напрямую зависит от настройки гиперпараметров моделей. В данной работе рассматривается классификатор k-ближайших соседей (k-Nearest Neighbors, KNN), который используется для идентификации жестов из пользовательского словаря. 

Эффективность KNN определяется тремя ключевыми параметрами:
1. Количество соседей ($k$);
2. Метрика расстояния (метрическое пространство);
3. Весовые коэффициенты соседей (функция влияния).

Использование стандартных параметров (например, $k=5$) часто приводит к переобучению или недостаточному обобщению на новых данных пользователя. Таким образом, возникает задача глобальной оптимизации — нахождения такого набора параметров, который максимизирует точность распознавания.

### 1.2. Цель работы
Целью данного исследования является проведение сравнительного анализа четырех различных стратегий оптимизации (Grid Search, Random Search, Genetic Algorithm, Bayesian Optimization) и выбор наиболее эффективной архитектуры для реализации в системе с функцией обучения.

---

## 2. Математическая постановка задачи оптимизации
Пусть $\Theta$ — пространство поиска гиперпараметров, где $\theta = (k, m, w) \in \Theta$.
Целевая функция $f(\theta)$ определяется как среднее значение F1-меры на кросс-валидации:

$$ f(\theta) = \frac{1}{V} \sum_{i=1}^{V} F_1(M(\theta), \mathcal{D}_i) \to \max_{\theta \in \Theta} $$

Где:
- $V$ — количество блоков кросс-валидации (в работе $V=5$);
- $M(\theta)$ — модель KNN с параметрами $\theta$;
- $\mathcal{D}_i$ — $i$-й блок данных.

Ограничения пространства $\Theta$:
- $k \in \{1, 3, 5, ..., 21\}$ (целочисленные нечетные значения);
- $m \in \{L_1 (\text{Manhattan}), L_2 (\text{Euclidean}), L_\infty (\text{Chebyshev})\}$;
- $w \in \{\text{uniform, distance}\}$.

## 3. Подробный анализ методов оптимизации

### 3.1. Метод полного перебора (Grid Search)
**Описание:** Алгоритм выполняет исчерпывающий поиск по заранее определенной сетке параметров. 
**Алгоритм:**
1. Для каждого значения $k$ из набора $K$;
2. Для каждой метрики $m$ из набора $M$;
3. Для каждого типа весов $w$ из набора $W$;
4. Обучить модель и вычислить $f(k, m, w)$.
5. Выбрать комбинацию с максимальным результатом.

**Сложность:** $O(|K| \cdot |M| \cdot |W|)$. При увеличении числа параметров сложность растет экспоненциально («проклятие размерности»).

### 3.2. Метод случайного поиска (Random Search)
**Описание:** Вместо перебора всех точек сетки, алгоритм выбирает случайные комбинации из заданных распределений.
**Обоснование:** Согласно исследованиям (Bengio et al.), случайный поиск эффективнее Grid Search, так как он не тратит ресурсы на перебор неважных параметров и может найти «узкие» максимумы, пропущенные сеткой.
**Сложность:** Фиксированное количество итераций $N$.

### 3.3. Генетический алгоритм (Genetic Algorithm)
**Описание:** Эволюционный метод, имитирующий естественный отбор.
**Процесс:**
1. **Инициализация:** Создание случайной популяции «хромосом» (наборов параметров).
2. **Оценка (Fitness):** Вычисление точности для каждой особи.
3. **Селекция:** Отбор лучших особей для размножения.
4. **Кроссовер и Мутация:** Создание новых решений путем комбинирования генов родителей и внесения случайных правок.
**Применение:** Эффективен для дискретных пространств, но требует настройки параметров самого алгоритма (шанс мутации, размер популяции).

### 3.4. Байесовская оптимизация (Bayesian Optimization)
**Описание:** Использование вероятностной модели (суррогатной модели) целевой функции для интеллектуального выбора следующих точек.
**Математическая база:**
- **Априорное распределение:** Обычно Гауссовский процесс.
- **Функция сбора (Acquisition Function):** Определяет баланс между исследованием новых областей (exploration) и эксплуатацией известных максимумов (exploitation).
**Преимущество:** Требует на порядок меньше итераций, чем случайный поиск, так как «учится» на результатах предыдущих запусков.

## 6. Программная реализация (Листинг)

Ниже представлен детализированный код системы оптимизации с использованием библиотеки `Optuna`.

```python
# Листинг 1. Интеллектуальный модуль оптимизации гиперпараметров
import optuna
import numpy as np
from sklearn.model_selection import cross_val_score
from sklearn.neighbors import KNeighborsClassifier
import matplotlib.pyplot as plt
from pathlib import Path

class GestureModelOptimizer:
    """
    Класс для автоматизированного поиска оптимальных параметров классификатора.
    Использует Байесовскую оптимизацию на базе TPE.
    """
    
    def __init__(self, features, labels):
        self.X = features
        self.y = labels
        self.study = None

    def objective(self, trial):
        # 1. Определение пространства поиска
        k = trial.suggest_int('n_neighbors', 1, 15, step=2)
        metric = trial.suggest_categorical('metric', 
                                         ['euclidean', 'manhattan', 'chebyshev'])
        weights = trial.suggest_categorical('weights', ['uniform', 'distance'])
        
        clf = KNeighborsClassifier(n_neighbors=k, metric=metric, weights=weights)
        
        # 2. Оценка качества через кросс-валидацию
        score = cross_val_score(clf, self.X, self.y, cv=3, scoring='accuracy').mean()
        return score

    def optimize(self, n_trials=50):
        """Запуск процесса поиска лучшей конфигурации."""
        self.study = optuna.create_study(direction='maximize')
        self.study.optimize(self.objective, n_trials=n_trials)
        return self.study.best_params

    def save_results_plots(self, output_dir="docs/plots"):
        """Сохранение графиков анализа."""
        Path(output_dir).mkdir(parents=True, exist_ok=True)
        
        # Визуализация истории оптимизации
        plt.figure(figsize=(10, 6))
        values = [t.value for t in self.study.trials if t.value is not None]
        plt.plot(values, marker='o', label='Accuracy')
        plt.plot(np.maximum.accumulate(values), '--r', label='Best Accuracy')
        plt.title('История оптимизации гиперпараметров')
        plt.xlabel('Итерация')
        plt.ylabel('Точность')
        plt.legend()
        plt.savefig(f"{output_dir}/opt_history.png")
        plt.close()

# Пример вызова в системе
```
