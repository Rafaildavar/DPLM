GestureBind: Gesture Assistant — Отчёт по проекту
Этап 1 — Базовый модуль CV (видеопоток, MediaPipe Hands, нормализация)

Цели этапа:
- Захват видеопотока с веб‑камеры (macOS, M1) через OpenCV.
- Обнаружение рук и извлечение 21 ландмарка с помощью MediaPipe Hands.
- Отрисовка скелета руки поверх видео для визуальной валидации.
- Нормализация координат (инвариантность к положению и масштабу).
- Вывод нормализованных координат в консоль для последующей записи фич.

Детали реализации и решения:
- Бэкенд захвата: cv2.CAP_AVFOUNDATION (стабильный для macOS ARM). При проблемах — без флага или индекс камеры 1.
- MediaPipe Hands: static_image_mode=False, max_num_hands=1, model_complexity=1, min_detection_confidence=0.6, min_tracking_confidence=0.6.
- Отзеркаливание кадра (cv2.flip) для удобства пользователю.
- Нормализация методом wrist_scale: вычитание запястья (landmark 0) и деление на максимум L2‑дистанций.
- Выход из приложения по клавише q.

Команды установки (внутри .venv):
- python -m pip install --upgrade pip
- pip install opencv-python mediapipe numpy

Команда запуска модуля:
- python cv/realtime_hands.py

Результаты и критерии готовности этапа:
- Окно с видеопотоком и отрисованным скелетом руки.
- В консоли печатаются нормализованные 21×2 координаты при наличии руки в кадре.
- Стабильная работа 20+ FPS на MacBook Air M1.

Проблемы и обходные пути:
- Чёрное окно/нет доступа к камере: проверить System Settings → Privacy & Security → Camera.
- Если AVFoundation не работает: использовать cv2.VideoCapture(0) без второго аргумента или сменить индекс камеры.
- Ошибки protobuf/mediapipe: pip install --upgrade protobuf
