DPLM: Gesture Assistant — Отчёт по проекту
Этап 0 — Инициализация проекта

Цели этапа:
- Создание структуры каталогов проекта.
- Подготовка базовых файлов (.gitignore, README.md, requirements.txt).
- Инициализация Git-репозитория, создание ветки dev, первый коммит и тег v0.1.0.

Структура каталогов:
- app/ — исходники приложения (GUI, логика)
- cv/ — модули CV/ML (детекция, нормализация, классификация)
- data/ — пользовательские данные/словарь жестов
- models/ — сериализованные модели/веса
- scripts/ — сервисные скрипты
- tests/ — тесты

Созданные файлы:
- .gitignore
