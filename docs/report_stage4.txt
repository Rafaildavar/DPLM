GestureBind: Gesture Assistant — Отчёт по проекту
Этап 4 — Онлайн‑классификация и озвучивание (TTS)

Цели этапа:
- Интегрировать обученную модель (KNN) в реальный видеопоток.
- Выполнять предсказания жеста в реальном времени.
- Озвучивать распознанный жест с помощью pyttsx3 (офлайн, macOS‑дружелюбно).

Дизайн решения:
- Захват видео: OpenCV + MediaPipe Hands, как на Этапе 1.
- Формирование признака: кадр → нормализованные ландмарки (одна/две руки) → вектор.
- Скользящее окно из последних N кадров → усреднение по времени → предсказание KNN.
- Дебаунс/анти‑флаттер: озвучиваем только при смене предсказанного класса и таймауте.
- Параметры CLI: пути к модели/классам, длина окна, флаг включения TTS.

Команда запуска (пример):
- python cv/realtime_infer.py --model models/knn.pkl --classes models/classes.json \
    --feature-dim-file models/feature_dim.txt --window 30 --tts

Критерии готовности:
- В окне отображается скелет руки; предсказанный жест — в заголовке кадра.
- При смене класса голосом произносится метка жеста.

Проблемы и обходные пути:
- Если окно пустое (нет руки) — используем нулевой вектор; избегаем ложных срабатываний за счёт окна и дебаунса.
- Если отличалась размерность признака — сверяемся с feature_dim.txt и корректно формируем вектор (одна/две руки).
