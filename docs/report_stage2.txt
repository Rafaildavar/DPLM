DPLM: Gesture Assistant — Отчёт по проекту
Этап 2 — Запись жестов (сбор пользовательских образцов)

Цели этапа:
- Предоставить возможность пользователю записывать собственные жесты.
- Сохранять несколько примеров (семплов) каждого жеста для дальнейшего обучения классификатора.
- Формат хранения: NPY (numpy) в структуре data/gestures/{label}/sample_XXXX.npy.

Детали реализации и решения:
- Используется MediaPipe Hands (как в Этапе 1) для извлечения 21 ландмарка.
- Нормализация координат: метод wrist_scale (относительно запястья и масштаба).
- Управление записью: клавиши —
  - s: начать/остановить запись семпла (в буфер)
  - n: сохранить буфер как новый sample_XXXX.npy в папку жеста
  - q: выход из приложения
- Параметры запуска:
  - --label <имя_жеста> (обязателен)
  - --num-samples <N> (целевое число семплов, по умолчанию 20)
  - --two-hands (опционально: учитывать вторую руку — по умолчанию одна)

Требования к данным:
- Для каждого семпла сохраняется последовательность нормализованных кадров (T × 21 × 2).
- Рекомендуемый минимальный набор: 20–30 семплов на жест.

Критерии готовности:
- Папки вида data/gestures/<label>/ с файлами sample_XXXX.npy появляются после записи.
- В консоли счётчик сохранённых семплов и подсказки по клавишам.

Проблемы и обходные пути:
- Нет детекции руки: проверить освещённость, фон, расстояние до камеры.
- Низкий FPS: уменьшить разрешение, model_complexity=0.
