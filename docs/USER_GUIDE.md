# GestureBind: инструкция пользователя

Эта инструкция предназначена для участников macOS beta-тестирования. Для
готовой сборки не нужны Python, Terminal или установка зависимостей.

## 1. Перед установкой

Текущая beta рассчитана на Mac с Apple Silicon (`M1` или новее), macOS 14
Sonoma или новее, минимум 8 GB оперативной памяти, 3 GB свободного места и
рабочую веб-камеру. Для частого переобучения моделей рекомендуется 16 GB RAM и
5 GB свободного места.

## 2. Скачать и установить

1. Откройте страницу [GestureBind Releases](https://github.com/Rafaildavar/GestureBind/releases).
2. Выберите актуальную beta-версию и раскройте блок `Assets`.
3. Скачайте `GestureBind-macos-<version>.dmg`. Не скачивайте `Source code`:
   это исходники, а не готовое приложение.
4. Откройте DMG и перетащите `GestureBind.app` на ярлык `Applications`.
5. Дождитесь копирования, извлеките образ и откройте папку `Applications`.
6. Нажмите на `GestureBind` правой кнопкой мыши, выберите `Open`, затем ещё раз
   подтвердите запуск.

Приложение пока не notarized, поэтому обычный двойной клик при первом запуске
может быть заблокирован Gatekeeper. Используйте только образ, скачанный со
страницы релизов проекта. Если macOS сообщает, что файл повреждён, не обходите
защиту через Terminal: скачайте DMG повторно и сообщите об ошибке разработчику.

Если у релиза нет DMG, можно использовать резервный
`GestureBind-macos-<version>.zip`: распакуйте архив, перенесите
`GestureBind.app` в `Applications` и продолжите с шага 6. Если нет и ZIP, этот
релиз содержит только исходный код и не подходит для установки.

## 3. Разрешения macOS

GestureBind запрашивает только те разрешения, которые нужны выбранным функциям.

| Разрешение | Когда нужно |
|---|---|
| Camera | обязательно для записи и распознавания жестов |
| Accessibility | для hotkeys, управления курсором и части системных команд |
| Automation | для действий, которые управляют другими приложениями macOS |
| Microphone | только для опциональных голосовых функций |

Разрешения можно изменить в `System Settings -> Privacy & Security`. Не нужно
выдавать Accessibility, Automation или Microphone, если соответствующие
функции не используются.

## 4. Первый безопасный запуск

1. Откройте `Настройки` и оставьте `Выполнять команды по жесту` выключенным,
   пока не будет создана и проверена первая привязка.
2. В разделе `Приватность` решите, отправлять ли анонимную статистику качества.
   Она выключена по умолчанию и не нужна для работы приложения.
3. Перейдите в `Обучение`.

## 5. Записать свой жест

1. Введите понятное уникальное имя, например `palm_open`.
2. Выберите тип:
   - `Статический` для неподвижной позы руки;
   - `Динамический` для движения с заметной траекторией.
3. Для первого теста оставьте предложенное число дублей и кадров.
4. Нажмите `Записать и обновить модель`.
5. Держите в кадре одну руку и дождитесь завершения всех дублей и обучения.

Для устойчивого распознавания немного меняйте расстояние до камеры и угол руки
между дублями, но сохраняйте смысл жеста. Используйте ровное освещение,
контрастный фон и полностью возвращайте руку в исходное положение перед новым
динамическим дублем. Не показывайте вторую руку: текущий MVP работает в
одноручном режиме.

После завершения откройте `Жесты` и убедитесь, что новый класс и записи появились
в списке. Раздел `Датасет` позволяет проверить число локальных примеров.

## 6. Привязать действие

### Вручную

1. Откройте `Привязки` и выберите записанный жест.
2. Оставьте режим `Одна команда` или выберите сценарий из нескольких шагов.
3. Выберите категорию, действие и заполните появившиеся параметры.
4. Нажмите `Проверить запуск`. Для первого теста используйте безвредное действие,
   например открытие Safari или показ уведомления.
5. Если результат верный, нажмите `Сохранить привязку`.

### Через агента

1. В поле агента напишите, например:
   `Привяжи жест palm_open к открытию Safari`.
2. Отправьте запрос и дождитесь итогового ответа агента.
3. Проверьте найденный жест и предложенное действие.
4. Нажмите `Заполнить`, затем `Проверить запуск` и только после проверки
   `Сохранить`.

Агент не сохраняет и не исполняет привязку без явного действия пользователя.
По умолчанию доступен локальный разбор запроса. Если владелец сборки отдельно
подключил Mistral, очищенный текст запроса и контекст текущей задачи могут быть
переданы этому провайдеру. Не вводите в запросы пароли, токены и персональные
данные.

## 7. Включить распознавание

1. Вернитесь на `Главную`.
2. Включите `Жесты` и, когда будете готовы к реальному действию,
   `Выполнять команды`.
3. Нажмите `Включить` и покажите записанный жест одной рукой.
4. Проверьте распознанный класс, confidence и блок `Последнее действие`.
5. Нажмите `Остановить`, когда управление жестами больше не нужно.

Кнопки обратной связи под камерой позволяют отметить верное, неверное или
пропущенное распознавание. Эта информация остаётся локальной, пока пользователь
сам не включит анонимную телеметрию.

## 8. Где хранятся данные

Все пользовательские данные готовой macOS-сборки находятся локально в
`~/.dplm/`:

| Данные | Путь |
|---|---|
| Записи жестов | `~/.dplm/data/gestures/` |
| Привязки и локальная БД | `~/.dplm/dplm.sqlite` |
| Настройки | `~/.dplm/config.json` |
| Логи и состояние телеметрии | `~/.dplm/logs/` |

Кадры камеры, landmarks и записи жестов не отправляются в облако. Подробные
исключения для добровольной телеметрии, Mistral и web research описаны в
[разделе безопасности README](https://github.com/Rafaildavar/GestureBind#безопасность-и-приватность).

Чтобы удалить приложение, завершите GestureBind и перенесите его из
`Applications` в корзину. Локальные жесты и настройки при этом сохранятся. Для
полного удаления данных откройте в Finder `Go -> Go to Folder`, введите
`~/.dplm` и удалите эту папку. Это действие необратимо: сначала сохраните копию,
если хотите использовать свои жесты позже.

## 9. Частые проблемы

| Проблема | Что проверить |
|---|---|
| В релизе нет DMG | выбран релиз только с исходниками; нужен asset `GestureBind-macos-<version>.dmg` |
| Приложение не открывается | запустите через правый клик -> `Open`; не обходите сообщение о повреждённом файле через Terminal |
| Камера не включается | закройте другие приложения с камерой и проверьте `Privacy & Security -> Camera` |
| Команда не выполняется | включите `Выполнять команды`, проверьте сохранённую привязку и разрешение Accessibility |
| Жест часто пропускается | улучшите освещение, держите всю руку в кадре и перезапишите более разнообразные дубли |
| Возникают ложные команды | отключите выполнение, перезапишите похожие классы более различимо и снова проверьте каждый жест |
| Mac на Intel | текущий beta-образ собран для Apple Silicon; Intel-артефакт пока не публикуется |

## 10. Сообщить о проблеме

В отчёте укажите версию GestureBind, версию macOS, модель процессора, объём RAM,
точные шаги, ожидаемый и фактический результат. Скриншоты и файлы из
`~/.dplm/logs/` прикладывайте только после проверки, что в них нет личной
информации. Ошибку можно создать в
[GitHub Issues](https://github.com/Rafaildavar/GestureBind/issues).
