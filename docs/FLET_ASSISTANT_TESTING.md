# Проверка Flet-ассистента DPLM

Этот файл фиксирует короткий сценарий проверки следующего этапа: GUI-настройки,
локальный конфиг, PostgreSQL/SQLite, модель, датасет и логирование.

## CLI smoke

Без открытия камеры:

```bash
python -m scripts.dplm_smoke
```

С проверкой выбранной камеры:

```bash
python -m scripts.dplm_smoke --camera
```

Код выхода `0` означает, что критических ошибок нет. Предупреждения допустимы,
например если переменные из `.env` переопределяют `~/.dplm/config.json`.

## GUI smoke

```bash
python -m app.flet_app.main
```

Дальше в приложении:

1. Открыть экран `Настройки`.
2. Нажать `Обновить статус`.
3. Нажать `Запустить самопроверку`.
4. При необходимости включить `Открывать камеру во время проверки` и повторить.
5. Нажать `Запустить распознавание` и проверить, что камера открылась.
6. Вернуться на `Главная`, показать жест и проверить блок `Последние события`.
   Там должна появиться метка жеста, уверенность и, если привязка сработала,
   имя выполненной команды.

## PostgreSQL

Если `.env` указывает на PostgreSQL, перед проверкой нужен контейнер:

```bash
docker compose up -d db
docker compose ps
```

Ожидаемый статус: `dplm-postgres` healthy, порт `5433->5432`.
