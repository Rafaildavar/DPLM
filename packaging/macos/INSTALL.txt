GESTUREBIND: УСТАНОВКА НА macOS

Требования: Apple Silicon (M1 или новее), macOS 14+, 8 GB RAM,
не менее 3 GB свободного места и рабочая камера.

1. Откройте скачанный DMG.
2. Перетащите GestureBind в папку Applications.
3. Дождитесь копирования и извлеките DMG.
4. Запускайте GestureBind только из Applications, не из открытого DMG.
   При запуске из DMG приложение покажет напоминание об установке и завершится.
5. При первом запуске разрешите доступ к Camera.
6. Для курсора, hotkeys и части системных команд дополнительно разрешите
   GestureBind в System Settings -> Privacy & Security -> Accessibility,
   затем перезапустите приложение.

ЕСЛИ macOS ПИШЕТ:
«Программу не удаётся проверить на наличие вредоносного ПО»

Текущая beta пока не notarized. Закройте предупреждение, затем:

1. Откройте System Settings -> Privacy & Security.
2. Прокрутите страницу до раздела Security.
3. Рядом с сообщением о GestureBind нажмите Open Anyway
   («Всё равно открыть» / «Подтвердить вход»).
4. Подтвердите вход в macOS и в следующем окне нажмите Open.

В macOS Catalina и более старом интерфейсе этот пункт находится в
System Preferences -> Security & Privacy -> General.

После подтверждения GestureBind сохраняется в списке разрешённых приложений,
и его можно запускать из Applications обычным двойным нажатием.

Не отключайте Gatekeeper и не удаляйте quarantine-атрибут через Terminal.
Используйте только DMG со страницы GitHub Releases проекта.

Пользовательские данные хранятся локально в ~/.dplm/. Публичная beta не
содержит общего MISTRAL_API_KEY: MAS работает локально, пока пользователь сам не
подключит Mistral в Настройки -> MAS и LLM. Личный ключ хранится в системном
Keychain. Полная инструкция находится в USER_GUIDE.md внутри этого DMG.
